# fgetpriority 开发约定

本目录归 Developer，遵守根目录 AGENTS.md。

- 当前为目标限定的功能实现；成功构建只算 Developer 自检，不是独立审计或设备可用结论。
- `fgp_target.h` 绑定指定镜像函数、加载器及 KP 回调帧 ABI，不是可移植 Linux 结构体布局表。
- 条件逻辑仅覆盖已确认 `CONFIG_USER_NS=n` 的目标；支持其他配置前必须补目标证据和 namespace 映射。
- 四个原调用点与 KP 帧必须通过代码指纹和指令检查；不得重新引入直接远距离 BL。
- 回调只执行不睡眠操作，使用原调用返回地址限定作用域；不得在回调内添加日志风暴、等待、工作队列或主动调度。
- 退出只撤销本模块回调并等待任务/中断侧在途执行，不走立即释放 KP 跳板的默认 unhook/unwrap。
- 注册后必须核验入口与 transit 字节；失败时撤销并排空，不能仅根据注册返回值宣告启用。
- 在安装、回滚和卸载协议完成独立复核前，不启用写入路径（包括设备加载）；本轮源码实现不构成上机许可，原始崩溃现场按根目录升级规则处理。
- 产物输出到新的空目录，不覆盖探索件或归档件。
